# 科学约束卡：lens-imaging（景深之谜 · 光圈与弥散圆）

> 按 docs/ANIM-QC.md 第三节格式，动手前先立卡，验收时逐行核对。
> 灵感手法参照 sael.net/plane-of-focus（焦平面=扫过场景的发光薄片 + 弥散圆可视化），
> 物理计算不照搬任何网页，全部由下述公式本地推导。

## 原理（只许一个）
薄透镜公式 `1/u + 1/v = 1/f` 决定每个物点的像点位置；
对焦点 `s` 的像平面在 `v_s`；离焦物点 `u` 的像点落在传感器前/后，
在传感器平面上形成**弥散圆**，直径 `c = D·|v(u) − v_s| / v(u)`，其中入瞳直径 `D = f/N`。
`c ≤ c0`（容许弥散圆，全画幅取 0.030 mm）的物距区间 = 景深。
超焦距 `H = f²/(N·c0) + f`。本动画只演示这一个机理链：光圈 N → 入瞳 D → 弥散圆 c → 景深厚薄。

## 不变量（参数 min→max 必须恒成立）
1. 任意物距 u 的像距 v 满足 `1/u + 1/v = 1/f`（f = 50 mm 恒定）；
2. 合焦阈值 c0 = 0.030 mm 不随参数变；
3. 对焦距离处 c ≡ 0 —— 焦平面上的物体永远锐利，任何光圈下成立；
4. 超焦距 H 对给定 N 恒定（f/2 ≈ 41.7 m，f/16 ≈ 5.3 m）；
5. 虚化盘直径与离焦量 |v(u) − v_s| 严格单调。

## 禁忌（常见错误画法）
1. 禁止把光圈画成只改画面明暗（那是曝光，不是景深机理）；
2. 禁止让焦平面上的物体也出现虚化；
3. 禁止把 f/16 的入瞳画得比 f/2 大（f 数与孔径反比，最易画反）；
4. 禁止让焦平面薄片随光圈变厚 —— 薄片是对焦面，厚度变化的只有景深区间带；
5. 禁止焦前/焦后模糊不区分（像点在传感器前 vs 后，是两个方向）。

## 参数质变点（无质变不配做滑块）
- **光圈 N（f/2 → f/16）**：f/2 时三层景物仅对焦层清晰（浅景深），f/16 时树/屋/山全部落入景深（深景深）——清晰主体数 1 → 3，是结构/相态改变，不是"变快变慢"；
- **对焦环 s（2 → 30 m）**：焦平面薄片扫过 树(3.5 m)/屋(7 m)/山(30 m) 时，清晰主体发生 前景 ⇄ 中景 ⇄ 远景 切换。

## 数值锚定（真实参数，军规3：数值必须自洽）
- 镜头：50 mm 定焦，全画幅 36×24 mm，c0 = 0.030 mm；
- 入瞳：f/2 → D=25.0 mm，f/16 → D=3.1 mm；
- 景物：树 3.5 m / 屋 7 m / 山 30 m（取值经 CoC 公式核算：对焦 7 m 时 f/2.8 下三者 c 分别为 0.127/0/0.099 mm（仅屋清晰），f/16 下 0.022/0/0.017 mm（全清晰），质变可复现）；
- 景深带由 c(u) ≤ c0 对 0.4 m–10 km 数值扫描求得，与渲染共用同一 c(u) 函数（画什么就算什么）。

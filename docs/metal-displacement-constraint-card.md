# 科学约束卡：metal-displacement（为什么铁钉放进硫酸铜溶液会变红？）

> 按 docs/ANIM-QC.md 第三节格式，动手前先立卡，验收时逐行核对。
> 可视化手法回灌自化学地牢已验证的 3D 演示（chemistry-rpg `src/fx3d/displacement3d.js`，
> 其化学准确性经该项目 docs/化学复核_v1.0.md 复核表 #12）：发光电子流粒子、
> 铜晶只增不减、溶液蓝→浅绿、全程无气泡。

## 原理（只许一个）
置换反应 `Fe + CuSO₄ → FeSO₄ + Cu` 的粒子级机理：
铁原子失去 2 个电子变成 Fe²⁺ 进入溶液（`Fe − 2e⁻ → Fe²⁺`，浅绿色）；
电子经铁钉表面传导给溶液中的 Cu²⁺，铜离子得电子还原为铜原子并在钉面沉积
（`Cu²⁺ + 2e⁻ → Cu`，红色）。电子流向恒定：**铁钉 → 铜离子**，永不反向。
电化学判据：E°池 = E°(Cu²⁺/Cu) − E°(Fe²⁺/Fe) = 0.34 − (−0.44) = **+0.78 V > 0**，常温自发。
本动画只演示这一条机理链：铁失电子 → 电子流向铜离子 → 铜沉积 + 亚铁离子入液。

## 不变量（参数 min→max 必须恒成立）
1. **电荷/原子守恒**：每沉积 1 个 Cu 微粒，必有 1 个 Cu²⁺ 光点消失、1 个 Fe²⁺ 光点新生
   （画面三类粒子计数满足 ΔCu²⁺ = −ΔCu = −ΔFe²⁺，读数面板同步显示）；
2. **铜只沉积不回头**：反应进度 progress 单调不减；钉面红色覆盖与铜晶微粒只增不减，
   暂停、拖参数、甚至反应"完成"后也不褪色（置换反应常温不可逆）；
3. **不产气**：任何参数、任何时刻画面不得出现气泡（本反应无气体生成物）；
4. **溶液变色方向固定**：蓝（CuSO₄）→ 浅绿（FeSO₄），由 [Cu²⁺] 降、[Fe²⁺] 升驱动，永不反向；
5. **电子流向固定**：发光电子粒子起点永远在钉面、终点永远在溶液中的自由 Cu²⁺ 上。

## 禁忌（常见错误画法）
1. 禁止出现气泡，更禁止把 Cu²⁺ 画成气泡状（本反应无气体，气泡是"铁遇酸"的张冠李戴）；
2. 禁止溶液由绿变蓝或蓝绿来回震荡（变色方向反 = 反应方向画反）；
3. 禁止电子流从溶液流向铁钉（方向反；得电子的是 Cu²⁺，失电子的是 Fe）；
4. 禁止铜晶体/钉面红色随时间缩小、消失或"溶回去"（把可逆平衡错套到置换反应）；
5. 禁止浓度滑块只改播放速度——浓度必须同时改变离子数量、颜色深浅与最终覆盖率；
6. 禁止把 Cu 画成蓝色、Fe²⁺ 画成黄色（Fe³⁺ 才黄，Fe²⁺ 浅绿）。

## 参数质变点（无质变不配做滑块）
- **浓度（稀 ~0.05 mol/L ⇄ 浓 ~1.0 mol/L）**：铁钉过量、Cu²⁺ 有限——
  - 浓：Cu²⁺ 光点密集、初始深蓝，Cu²⁺ 充足可使钉面**全覆盖**变红、铜晶满布，完成后明显浅绿；
  - 稀：光点稀疏、初始淡蓝，Cu²⁺ 耗尽时钉面**只能局部镀铜**（覆盖率上限 ~1/3），
    完成后仅极淡绿、反应也慢（有效碰撞少）。
  - 质变在**结构**：最终覆盖率与颜色格局随浓度分档，不是"变快变慢"。

## 数值锚定（真实参数，军规3：数值必须自洽）
- E°(Fe²⁺/Fe) = −0.44 V，E°(Cu²⁺/Cu) = +0.34 V，E°池 = +0.78 V > 0 → 常温自发
  （25 °C 标准电极电势，人教版高中化学教科书 / CRC Handbook of Chemistry and Physics）；
- 现象锚定：CuSO₄ 溶液蓝色、FeSO₄ 溶液浅绿色、Cu 红色固体（人教版九年级"金属的化学性质"）；
- 动力学只做**相对**锚定（教学示意，非精确动力学）：速率 ∝ 浓度 × 剩余 Cu²⁺ 份额，
  浓溶液（1 mol/L）相对速率取稀溶液（0.05 mol/L）的数倍，二者同屏对比可复现；
- 覆盖率模型：cover = min(1, K·n₀·progress)，n₀ ∝ 浓度为初始 Cu²⁺ 相对量，
  K 标定使 浓+反应完成 时 cover = 1；颜色由同一组 n₀/progress 实时计算（画什么就算什么）。

# 数理通 · 初高中数理化交互实验室

纯静态教育网站：初中+高中三科交互知识点，所有公式集中在受测试的科学引擎中，渲染层只呈现、不改数值。

## 特性

- **黄金测试**：44 个"已知正确答案"断言（浏览器内可跑：打开"自检台"；命令行跑：`node tests/node-run.js`）
- **量纲运行时校验**：物理计算量纲不符直接抛错并阻断渲染
- **常数单一事实源**：`engine/constants.js` 统一管理，标注来源（教材约定值/CODATA/IUPAC）
- **零构建、零后端**：无 npm、无打包，直接部署静态文件
- **第三方库本地托管**：KaTeX / JSXGraph / three.js 已下载到 `vendor/`，离线可用

## 目录结构

```

├── index.html          # 单页应用入口（hash 路由）

│   ├── constants.js    # 常数与元素数据
│   ├── units.js        # 量纲系统

│   ├── physx.js        # 物理内核

├── vendor/             # KaTeX/JSXGraph/three.js 本地托管
└── tests/node-run.js   # Node 测试运行器
```

## 本地运行

无需安装任何东西（任选其一）：

```bash
# Python
python -m http.server 8765 --directory website

# 或 Node（有 npx 即可）
npx serve website
```

打开 `http://localhost:8765/`。

跑黄金测试（需要 Node）：

```bash
node website/tests/node-run.js
```

## 部署上线

站点是纯静态文件，以下任一方式均可直接上线：

### GitHub Pages（推荐）
1. 新建仓库，把 `website/` 目录内容推到仓库根目录（或保留 `website/` 子目录并在设置里指定）
2. Settings → Pages → Source 选分支 `/ (root)` → 保存
3. 访问 `https://<用户名>.github.io/<仓库名>/`

### Netlify / Vercel
直接拖拽 `website/` 目录到部署面板，或绑定仓库自动部署。无构建命令，输出目录即站点根目录。

### 任意静态服务器 / 对象存储
把 `website/` 内容上传到静态托管（OSS/COS/S3 + CDN 等）即可，无服务端逻辑。

## 扩展新知识点的方法

1. 公式写进 `engine/*.js`（纯函数，注明量纲）
2. 在 `engine/tests.js` 加黄金测试用例，跑通 `node tests/node-run.js`
3. 在 `modules/` 新建模块文件，`App.register({...})`，在 `index.html` 引入
4. 渲染层只调用引擎、只呈现结果

## 正确性约定（重要）

- 教学内容对齐现行课程标准；物理取教材约定值（g=9.8 N/kg 等），已在常数表标注
- 每个交互件的公式必须有对应黄金用例；量纲错误在运行时被拦截并显示（不静默）
- 超出课标近似范围的内容须明确标注，不做误导性动画
